# 01-Blinking-Heart

An interactive micro:bit program that toggles between a big heart and a small heart when Button A is pressed, and clears the screen when Button B is pressed.

## Features
- **Button A**: Toggle Heart / Small Heart animation.
- **Button B**: Clear screen.

## How to Test
Run locally inside Docker:
```bash
./run test 01-blinking-heart
```

## How to Run in MakeCode Simulator
1. Open [makecode.microbit.org](https://makecode.microbit.org/).
2. Create a new project.
3. Switch the top tab from **Blocks** to **JavaScript** (TypeScript).
4. Copy the entire contents of `main.ts` and paste them into the editor.
5. Click **Button A** and **Button B** in the interactive simulator on the left!
